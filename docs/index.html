How it works.

Three steps. Most documents go end-to-end in under five minutes, including the human review.

1

Drop a document

Click or drag a .pdf, .docx, or .pptx onto the audit page. The first scan is free without an account; sign in to remediate or run more.

2

Review every finding

Eight analyzers walk WCAG, 508, and PDF/UA rules. Each issue gets a plain-English explanation, an AI-suggested fix, and approve / edit / reject controls.

3

Approve and download

Approved fixes are baked into a remediated copy of the original file. Rejected items get queued for manual handling. Download the file plus a printable certificate.

Auto-fix policy: pick Conservative, Balanced, or Aggressive at intake to control how many AI suggestions are pre-approved on your behalf. You always have the final say.

Standards covered.

Each finding cites the rule it's enforcing. No black-box "trust us" results.

Self-host it.

The whole stack is open source. Run it locally for testing, or behind a Cloudflare Tunnel for production.

Quick start (dev)

git clone https://github.com/Maximilian741/508-Agent cd 508-Agent cp .env.example .env cd backend pip install -r requirements.txt python dev_run.py # in another terminal: cd frontend/frontend npm install npx expo start --web

The backend writes its live URL to backend/.runtime/backend_url.txt on startup. The frontend reads this file on first load, so you usually don't need to configure ports manually. See SHIP-CHECKLIST.md for the production deploy runbook.

Architecture.

Boring on purpose. FastAPI backend, Expo Router frontend, SQLite in dev, Postgres in prod. Cloudflare Tunnel terminates TLS so you don't need to expose a public IP.

Backend

FastAPI + SQLAlchemy on Python 3.11+. Eight analyzers, three writers (PDF / DOCX / PPTX), pluggable AI provider chain (Claude vision -> OpenAI -> heuristic fallback).

Frontend

Expo Router (React Native Web), TypeScript. Single-page-app build, hosted as static files behind nginx. Custom WebGL shaders for hero accents.

Production edge

Cloudflare Tunnel + Cloudflare Access for the admin and billing surfaces. nginx in front of uvicorn. Postgres for state, S3-compatible storage for files.

What it does well, and what it doesn't.

Honest about scope so you don't get surprised in production.

Handles well

Business documents (reports, contracts, proposals), structured Word docs, slide decks with proper outline, tagged PDFs, alt-text generation, language tagging, heading hierarchy, table headers.

Needs review

Documents the pipeline can't fix automatically land in a manual-review queue with the exact reason, so nothing breaks silently. You decide what to do with each item.

Not yet

Scanned PDFs without OCR pre-processing, complex scientific papers with equations, multi-language mixed-script documents, heavily form-driven PDFs with custom tab order. Roadmap.
